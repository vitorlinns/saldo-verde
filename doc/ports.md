# Portas do ambiente local

Este documento descreve as portas usadas localmente para o sistema.

## Frontend SaaS

- Frontend React + Vite: `http://localhost:5173`

## Backend SaaS

- Backend Node local: `http://localhost:4000`

## Site principal

- Site Next.js ou site estático (pasta `site/`): padrão do Next/Vite quando rodado com `npm run dev` (normalmente `http://localhost:3000` se não houver outra porta configurada)

## Observações

- O subdomínio de produção do SaaS será `https://app.saldoverde.pro`
- A API em produção ficará em `https://api.saldoverde.pro`
- A raiz do site permanecerá em `https://saldoverde.pro`
