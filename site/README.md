# Saldo Verde - Site

Site institucional para o software de finanças "Saldo Verde".

## Como usar

A partir da raiz do repositório:

```bash
npm install
npm run dev -- --hostname 127.0.0.1 --port 3000
```

Ou dentro da pasta do site:

```bash
cd site
npm install
npm run dev -- --hostname 127.0.0.1 --port 3000
```

> Se você quiser iniciar com Node 22 explicitamente:
>
> ```bash
> npm run dev:node22 -- --hostname 127.0.0.1 --port 3000
> ```

## Deploy

- Configure a raiz do projeto na Vercel como `site`
- Domínio de produção: `saldoverde.pro`
